# NumPy Masterclass: Python for Data Science & Machine Learning

Welcome to my repository for the **NumPy Masterclass**. This repository contains all my code, exercises, and projects as I master NumPy and its core applications in Data Science and Machine Learning.

---

## 🚀 About the Course
NumPy is the fundamental package for scientific computing in Python. This masterclass dives deep into high-performance array operations, vectorization, broadcasting, and how NumPy powers heavy-duty data science and machine learning libraries like Pandas, Scikit-Learn, and TensorFlow.

---

## 📚 Key Topics Covered
*   **Fundamentals:** NumPy arrays, data types, indexing, slicing, and reshaping.
*   **Performance:** Vectorization vs. loops, and memory management.
*   **Advanced Operations:** Broadcasting, universal functions (ufuncs), aggregation, and boolean masking.
*   **Linear Algebra:** Matrix multiplication, dot products, eigenvalues, and inversions.
*   **Data Science Integration:** Handling missing data, random sampling, and bridging with Pandas.
*   **Machine Learning Prep:** Feature scaling, distance metrics, and implementing basic ML algorithms from scratch using NumPy.
